# SmartITR (Smart Platform)

Initial Angular + Bootstrap website scaffold for multi-service workflows, starting with ITR filing.

## Included in this step
- Strict TypeScript configuration
- Bootstrap v5 global styling
- App shell with top navigation
- Lazy-loaded feature modules:
  - Landing
  - Auth
  - Dashboard
  - Questionnaire
  - DigiLocker
  - Summary
- Reactive Forms wired at root module level

## Run locally
```bash
npm install
npm start
```

If your environment blocks npm registry access, run in a network-enabled environment.
